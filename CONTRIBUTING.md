# Contributing

Thank you for helping improve FindIP Shield for WooCommerce.

1. Open an issue describing the change or bug.
2. Keep event payloads free of customer, product, cart, order, and payment identifiers.
3. Add or update tests for behavioral changes.
4. Run the PHP and JavaScript quality checks documented in the README.
5. Submit a focused pull request.

Do not report vulnerabilities publicly. Follow [SECURITY.md](SECURITY.md) instead.
